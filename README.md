# 坦克大战 Tank Battle

一个纯网页版坦克大战小游戏，使用原生 HTML5 Canvas 与 JavaScript 编写，无需任何依赖，打开 `index.html` 即可游玩。

## ✨ 特性

- 🎮 单文件实现，零依赖，双击即可运行
- 🕹️ 键盘操控：移动 + 射击
- 🧱 可破坏的砖墙与不可破坏的钢墙
- 🤖 敌方坦克 AI（随机移动 + 追踪 + 射击）
- 💥 粒子爆炸特效与流畅动画
- 🏆 计分、生命、关卡系统（共 5 关）
- 🛡️ 基地防守机制，基地被毁则游戏结束

## 🚀 快速开始

### 方式一：直接打开

直接双击 `index.html`，或在浏览器中打开该文件即可开始游戏。

### 方式二：本地服务器（推荐）

```bash
# 在项目目录下运行任意一个
python -m http.server 8000
# 或
npx serve .
```

然后访问 http://localhost:8000

## 🎯 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动坦克 |
| `空格` | 发射炮弹 |
| `P` | 暂停 / 继续 |

## 🎮 游戏规则

1. 你的基地位于屏幕底部中央，消灭所有敌方坦克并保护基地不被摧毁。
2. 敌方坦克会从屏幕顶部不断出现，追击并攻击你。
3. 砖墙可以被炮弹摧毁，钢墙无法摧毁，合理利用地形进行战斗。
4. 每关有若干敌方坦克，全部消灭即可进入下一关。
5. 你共有 3 条生命，基地被毁或生命耗尽则游戏结束。
